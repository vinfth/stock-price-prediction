# stock-price-prediction

Stock price Prediction Using Deep Learning

A deep learning project that predicts hotel review ratings from textual reviews using extreme gradient boosting and LSTM neural network.

Key Results Dataset: Ten years of DJI data for training 
LSTM R-squared: 97.01%

Technologies

Python · TensorFlow · Keras · Scikit-learn · Deep Learning

Pipeline

Raw stock data → LSTM → xgb selection → LSTM by xgb selection → Prediction
